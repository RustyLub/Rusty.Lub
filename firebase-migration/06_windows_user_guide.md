# Инструкция по миграции для пользователей Windows

Эта пошаговая инструкция предназначена для выполнения безопасного переноса данных без необходимости глубоких знаний программирования.

## Предварительные требования
1. Установленный **Node.js** (версия 18 или выше) на вашем компьютере с Windows.
2. Скачанный файл ключа доступа (Service Account Key) от старого проекта (например, `serviceAccountKey-old.json`) и нового проекта (`serviceAccountKey-new.json`).
   *⚠️ Никогда не передавайте эти файлы посторонним лицам и не выкладывайте в публичный доступ.*

## Пошаговый процесс
1. Откройте папку проекта на компьютере.
2. Перейдите в папку `firebase-migration`.
3. Установите необходимые зависимости для работы скриптов миграции:
   ```cmd
   npm install firebase-admin
   ```
4. Поместите файлы ключей доступа в папку `firebase-migration`.
5. Откройте терминал (Command Prompt или PowerShell) в папке `firebase-migration`.
6. Перед запуском любых операций убедитесь, что вы получили официальное разрешение и оценили квоты бесплатного тарифа.
