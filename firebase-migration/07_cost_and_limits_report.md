# Отчёт о потенциальных расходах и ограничениях бесплатного тарифа (Spark Plan)

Данный отчёт оценивает риски превышения лимитов и возможные финансовые затраты при переносе данных между проектами Firebase.

## 1. Лимиты бесплатного тарифа (Spark Plan)
В рамках бесплатного тарифа действуют следующие суточные квоты:
- **Чтение документов (Reads):** 50,000 в сутки.
- **Запись документов (Writes):** 20,000 в сутки.
- **Удаление документов (Deletes):** 20,000 в сутки.
- **Хранилище данных (Stored Data):** 1 ГБ всего.

## 2. Оценка объёма миграции
- Проект «справочник Rusty.Lub» содержит относительно небольшой объём текстовых данных (новости, чаты, настройки, несколько сотен или тысяч пользовательских профилей).
- Совокупный объем базы данных значительно меньше 1 ГБ (обычно в пределах 10–50 МБ).
- Количество документов для чтения при экспорте и записи при импорте оценивается в пределах нескольких тысяч, что **полностью укладывается в суточные лимиты бесплатного тарифа Spark**.

## 3. Меры предосторожности (Как избежать случайных списаний)
1. **Не подключайте кредитную карту / Blaze Plan** к новому проекту до завершения миграции. Находясь на тарифе Spark, любые операции, превышающие квоту, будут просто заблокированы системой без списания средств.
2. Проводите миграцию в часы наименьшей активности (или в один этап), чтобы не пересекаться с суточными лимитами чтения/записи работающего приложения.
