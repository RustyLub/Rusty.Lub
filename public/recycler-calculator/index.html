Калькулятор переработчика Rust

Оцените, сколько материалов можно получить из компонентов. Добавляйте предметы в очередь, задавайте количество и смотрите суммарный результат с выбранным коэффициентом эффективности.

Открыть калькулятор переработчика ↗
Инструмент откроется на основном сайте Rusty.Lub.

Как рассчитать переработку

  1. Найдите компонент через поиск или выберите категорию.
  2. Добавьте предмет в очередь и укажите количество.
  3. Выберите подходящий режим эффективности.
  4. Посмотрите сводку по получаемым материалам и измените состав очереди при необходимости.

Какие предметы можно учитывать

В базе калькулятора есть компоненты и другие предметы Rust: шестерёнки, металлические трубы, наборы для шитья, листовой металл, дорожные знаки, технический мусор и другие позиции. Поиск и фильтры помогают быстрее собрать список переработки.

Вместо ручного добавления каждого предмета можно загрузить один из подготовленных наборов: средний лут элитного ящика, набор военного ящика, компоненты после похода на нефтяную вышку или полный набор для фарма дороги.

Режимы эффективности

Интерфейс позволяет переключать коэффициенты 100%, 80%, 60% и 50%. В коде проекта они подписаны как варианты для красного переработчика, безопасной зоны, запитанной сети и неподключённой площадки. Выбранный коэффициент применяется к расчёту выхода материалов.

Поскольку условия переработки и игровые значения могут меняться, сверяйте выбранный режим с текущей механикой сервера и самой игры.

Зачем планировать очередь заранее

Предварительный расчёт помогает сравнить наборы компонентов, оценить ожидаемый скрап и материалы, а также решить, какие предметы стоит оставить для крафта или продажи. Это особенно удобно после фарма дорог, ящиков и монументов.

Частые вопросы

Можно ли добавить сразу несколько одинаковых компонентов?

Да. Для каждого предмета можно задать количество, а калькулятор суммирует результат.

Есть ли готовые наборы?

Да. Доступны пресеты для элитного и военного ящиков, нефтяной вышки и фарма дороги.

Можно ли менять эффективность?

Да. В интерфейсе есть варианты 100%, 80%, 60% и 50%.
